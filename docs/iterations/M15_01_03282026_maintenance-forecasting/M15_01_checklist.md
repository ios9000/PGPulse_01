## Deploy & Validate

### Step 12: Cross-compile and deploy to demo VM

```bash
cd ~/Projects/PGPulse_01

# Cross-compile
export GOOS=linux
export GOARCH=amd64
export CGO_ENABLED=0
go build -ldflags="-s -w" -o dist/pgpulse-server-linux-amd64 ./cmd/pgpulse-server
unset GOOS GOARCH CGO_ENABLED

# Deploy
scp dist/pgpulse-server-linux-amd64 demo@demo.example.com:/home/demo/pgpulse-demo/
ssh demo@demo.example.com 'sudo systemctl stop pgpulse && sudo cp /home/demo/pgpulse-demo/pgpulse-server-linux-amd64 /opt/pgpulse/bin/pgpulse-server && sudo chmod +x /opt/pgpulse/bin/pgpulse-server && sudo systemctl start pgpulse'
```

### Step 13: Enable forecast in config

```bash
ssh demo@demo.example.com

# Edit config — add forecast section
sudo nano /opt/pgpulse/configs/pgpulse.yml
```

Add to `pgpulse.yml`:

```yaml
forecast:
  enabled: true
  eta_window_size: 10
  eta_decay_factor: 0.85
  eta_min_samples: 4
  evaluation_interval: 5m
  min_data_points: 3
  lookback_window: 24h
  reindex_bloat_threshold_table: 0.40
  reindex_bloat_threshold_index: 0.30
  retention_days: 90
```

Restart after config change:

```bash
sudo systemctl restart pgpulse
```

### Step 15: Demo validation

```bash
ssh demo@demo.example.com

# 15a. Trigger a long vacuum
sudo -u postgres psql -p 5432 -d postgres -c "
CREATE TABLE IF NOT EXISTS forecast_test AS SELECT generate_series(1, 1000000) AS id, md5(random()::text) AS data;
DELETE FROM forecast_test WHERE id % 2 = 0;
VACUUM VERBOSE forecast_test;
"

# 15b. While vacuum runs, check ETA endpoint (from your local machine)
curl -s -H "Authorization: Bearer <token>" \
  https://demo.example.com:8989/api/v1/instances/<instance_id>/forecast/eta | jq .

# Expected: operations array with vacuum entry, confidence building from "estimating" to "medium" to "high"

# 15c. After vacuum completes, check operation history
curl -s -H "Authorization: Bearer <token>" \
  https://demo.example.com:8989/api/v1/instances/<instance_id>/forecast/history | jq .

# Expected: one completed vacuum with duration_sec, outcome="completed"

# 15d. Wait 5 minutes for NeedEvaluator to run, then check forecasts
curl -s -H "Authorization: Bearer <token>" \
  https://demo.example.com:8989/api/v1/instances/<instance_id>/forecast/needs | jq .

# Expected: forecasts for tables with dead tuples, status=predicted/not_needed

# 15e. Check UI
# Open browser → Instance Dashboard → verify NeedForecastCard visible
# Open browser → Progress page → verify ETA column present

# 15f. Edge case: clean shutdown
sudo systemctl stop pgpulse
# Check logs: should see "forecast retention cleanup" and no panics
sudo journalctl -u pgpulse --since "1 minute ago" | grep -i "forecast\|panic"

sudo systemctl start pgpulse

# 15g. Cleanup test table
sudo -u postgres psql -p 5432 -d postgres -c "DROP TABLE IF EXISTS forecast_test;"
```
